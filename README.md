# 家族树 Family Tree

一个基于 React 和 React Flow 构建的交互式家族族谱可视化应用。

## 项目背景

随着城市化进程加快和生活节奏加速，年轻人越来越记不住家族亲属关系。逢年过节聚会时，面对众多亲戚往往不知道该如何称呼；日常生活中，也很难快速识别遇到的亲属身份。这款家族树应用旨在帮助用户可视化管理家族成员信息，轻松维系家族情感纽带。

## 功能特点

- 交互式家族树可视化
- 添加和编辑家族成员
- 查看成员详细信息
- 拖拽和缩放支持
- 自动布局算法

## 技术栈

- **React 19** - UI 框架
- **Vite** - 构建工具
- **React Flow** (@xyflow/react) - 树状图可视化
- **Dagre** - 图布局算法
- **Zustand** - 状态管理
- **Tailwind CSS** - 样式

## 快速开始

### 前置要求

- Node.js

### 安装依赖

```bash
npm install
```

### 配置

在 [.env.local](.env.local) 中设置 `GEMINI_API_KEY`（如使用 AI 功能）。

### 使用

```bash
# 启动开发服务器
npm run dev
# 应用将在 `http://localhost:3000` 可用

# 构建生产版本
npm run build
# 预览生产构建
npm run preview
# 代码检查
npm run lint
```

## 未来应用方向

在遵守信息使用规定的前提下，本项目可拓展以下应用场景：

- **亲属人脸识别**：通过手机摄像头识别家族成员身份
- **车牌号识别**：识别亲属车辆，方便走亲访友时寻找停车位置
- **智能提醒**：亲属来访时自动提醒相关信息
- **权限授权**：为可信亲属提供门禁、车辆等授权管理
- **历史回忆**：已故亲人数字纪念馆，结合照片、视频、文字记录，家族迁徙历史地图
- **遗传分析**：家族遗传病史记录与管理
